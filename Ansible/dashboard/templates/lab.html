Remote machine setup

On the Linux machine, enable SSH and install Python using its package manager. For Debian / Kali / Ubuntu:

sudo apt install openssh-server python3
sudo systemctl enable --now ssh
hostname -I

Allow the configured SSH port through its firewall. Use the IP shown above. For key authentication, install this controller’s public key with ssh-copy-id username@address.

WinRM must be enabled on the Windows machine with a listener and firewall rule for the configured port. Use an administrator account. HTTPS requires a server certificate; choose the protocol that matches the existing listener.
